# ESPStudio Compiler Agent

Ứng dụng Windows hỗ trợ biên dịch và nạp chương trình lên ESP32 từ [ESPStudio](https://thamtrung151.github.io/tt-espstudio/).

Sản phẩm đang trong quá trình phát triển và hoàn thiện. Bộ cài dành cho Windows 10/11 x64; lần biên dịch đầu cần Internet để tải các công cụ cần thiết.

[Tải Agent 0.7.0 cho Windows](https://github.com/thamtrung151/agent-for-espstudio/releases/download/v0.7.0/TTESPStudio-Agent-0.7.0-win-x64.exe) · [Thông tin bản phát hành và checksum](https://github.com/thamtrung151/agent-for-espstudio/releases/tag/v0.7.0)

## Hướng dẫn và ví dụ

Tài liệu dành cho ESPStudio 0.7.8, gồm các bài lập trình Blockly cơ bản và điều khiển robot bốn bánh mecanum bằng PS2.

- [Hướng dẫn sử dụng PDF](https://github.com/thamtrung151/agent-for-espstudio/releases/download/guide-v0.7.8/TT_ESPStudio_Huong_Dan_Blockly_Mecanum.pdf): 19 trang với ảnh giao diện có màu.
- [Gói 13 project mẫu](https://github.com/thamtrung151/agent-for-espstudio/releases/download/guide-v0.7.8/TT_ESPStudio_Project_Mau_Blockly.zip): các file JSON để nhập vào ESPStudio, gồm bài nháy LED GPIO47 cho Newmania V1.0.
